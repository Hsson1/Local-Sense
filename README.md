# Local Sense MVP - منصة التجارب المحلية المؤمّنة

## نظرة عامة

**Local Sense** هو MVP (Minimum Viable Product) لمنصة تجارب محلية مؤمّنة تهدف إلى ربط المضيفين المحليين بالمستخدمين الباحثين عن تجارب أصيلة وفريدة. المنصة تدعم نموذج أعمال متعدد المصادر مع التركيز على الأمان والجودة.

## الميزات الأساسية

### للمستخدمين
- **تصفح التجارب المحلية** مع إمكانية البحث الجغرافي
- **حجز التجارب** مع الدفع المسبق عبر Stripe
- **عرض تفاصيل التجارب** مع الصور والأوصاف
- **واجهة مستخدم بسيطة وسهلة الاستخدام**

### للمضيفين
- **إنشاء وإدارة التجارب** من خلال لوحة تحكم مخصصة
- **تحديد الأسعار والقدرة الاستيعابية**
- **رفع الصور والمحتوى الوسائطي**
- **تتبع الحجوزات والإيرادات**

### للمنصة
- **نظام عمولة تلقائي** (15% من كل حجز)
- **نظام دفع آمن** عبر Stripe
- **إدارة المستخدمين والمضيفين**
- **قاعدة بيانات MongoDB للتخزين الآمن**

## التقنيات المستخدمة

### Backend
- **Node.js** مع Express.js
- **MongoDB** مع Mongoose ODM
- **JWT** للمصادقة والتوثيق
- **Stripe** لمعالجة المدفوعات
- **bcryptjs** لتشفير كلمات المرور

### Frontend
- **React.js** مع React Router
- **Axios** للتواصل مع API
- **CSS** للتصميم والتنسيق

## التثبيت والتشغيل

### متطلبات النظام
- Node.js (الإصدار 14 أو أحدث)
- npm أو yarn
- حساب MongoDB Atlas
- حساب Stripe للمدفوعات

### خطوات التثبيت

#### 1. تثبيت Backend
```bash
cd backend
npm install
cp .env.example .env
# قم بتحديث ملف .env بالمعلومات الصحيحة
npm run dev
```

#### 2. تثبيت Frontend
```bash
cd frontend
npm install
echo "REACT_APP_API_URL=http://localhost:5000" > .env
npm start
```

### متغيرات البيئة

#### Backend (.env)
```
MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/local-sense
JWT_SECRET=your_jwt_secret_here
STRIPE_SECRET_KEY=sk_test_your_stripe_key
CLIENT_URL=http://localhost:3000
```

#### Frontend (.env)
```
REACT_APP_API_URL=http://localhost:5000
```

## API Endpoints

### المصادقة
- `POST /api/auth/register` - تسجيل مستخدم جديد
- `POST /api/auth/login` - تسجيل الدخول

### التجارب
- `GET /api/experiences` - جلب قائمة التجارب
- `GET /api/experiences/:id` - جلب تفاصيل تجربة محددة
- `POST /api/experiences` - إنشاء تجربة جديدة (للمضيفين فقط)

### الحجوزات
- `POST /api/bookings/create-checkout-session` - إنشاء جلسة دفع Stripe
- `POST /api/bookings/webhook` - webhook لتأكيد الدفع
